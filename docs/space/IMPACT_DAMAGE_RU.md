# Повреждения при ударе о породу

Столкновение в поясе астероидов считается **локально**: важен не общий модуль
скорости корабля, а какая именно клетка коснулась камня и с какой скоростью она
в него **въезжает вдоль нормали контакта**.

```
удар по клетке = (v_closing / toughness_клетки)² × ориентация
               + (v_shear   / (5 × toughness))²
```

- `v_closing` — составляющая относительной скорости вдоль нормали контакта
  (то, что реально вминает деталь в камень);
- `v_shear` — то, что скользит вдоль камня (трение/срез);
- `toughness` — скорость, при которой свежая клетка разрушается одним ударом, м/с;
- ориентация — только для тонких пластин (панель, радиатор, обтекатель).

Квадрат, потому что разрушающий член удара о жёсткую породу — давление
торможения `½ρv²` (модель гидродинамического проникания). Скорость в 2 раза
больше — нагрузка в 4 раза больше: медленный тычок оставляет вмятину, быстрый
чирк срывает крыло.

## Куда попал — то и сломалось

Событие перебирает все клетки корабля и их шесть граней, и берёт контакт с
наибольшей закрывающей скоростью. Никакого «случайного списка деталей» больше
нет: удар по силовой клетке портит силовую клетку и **не трогает** солнечную
панель на другом конце корабля, даже если корабль летел очень быстро.

| Клетка | toughness, м/с | Что ломается |
|---|---:|---|
| силовая клетка / стол / крепление | 42 / 75 / 45 | корпус, несущий путь |
| пиро-кольцо | 30 | узел разделения |
| топливный бак | 26 | топливо этого отсека теряется |
| двигатель | 30 | тяга этого двигателя |
| бытовой отсек / лаборатория | 18 | разгерметизация |
| кислородный отсек | 14 | разгерметизация |
| полезная нагрузка | 22 | аппарат под обтекателем |
| обтекатель | 9 | панель сорвана, нагрузка под потоком |
| солнечная панель | 7 | выработка энергии |
| радиатор | 8 | сброс тепла |
| антенна / транспондер | 5 / 6 | связь |
| аккумулятор / гиродин | 13 | запас на затмение / ориентация |
| кресло управления | 15 | управление |
| стыковочный узел | 20 | этот порт больше не стыкуется |
| опоры | 18 | мягкая посадка без них — `NO_LEGS` |

Тонкие пластины (панель, радиатор, обтекатель) считаются по направлению:
удар **плашмя** по нормали панели — коэффициент 0.45 (нагрузка размазана по
площади), удар **в кромку** — 1.25 (срез с крепления).

## Что значит «разрушено»

Уничтоженная клетка **удаляется из нагрузки корабля**: из payload, из компиляции,
из массы, из тяги, из баков. Поэтому последствия настоящие, а не текстовые:

- сорвало панель — солнечной выработки больше нет;
- выбило двигатель — этот двигатель больше не даёт тяги;
- разорвало бак — топлива этого отсека больше нет;
- снесло кресло — управлять некому.

Целостность корпуса — это **доля массы, оставшаяся на корабле**. Снесли антенну
(8 кг) — почти ничего; снесли силовую клетку (120 кг) — заметно.

Если из остатков больше не собирается корабль (нет кресла, двигателя или
топливного пути), куча **не исчезает**: она становится обломком с нулевой тягой,
экипаж можно снять. Полная гибель — только когда не осталось ни одной клетки
(целостность 0): тогда экипаж погибает, судно удаляется.

## Разгерметизация

Пока это **заглушка AP**: удар по бытовому отсеку/кислороду пишет «воздух уходит»
и наносит 1 сердце экипажу. Настоящая утечка моль/давление/температура — это
`ChemMod` (`ChemAtmosphere`, поля утечек). Tank-contents API не опубликован
(ADR-0004), поэтому классы ChemMod **не импортируются**, а заглушка меняется на
реальную физику, когда API выйдет.

## Ограничения текущей модели

- «Крыло шаттла» в AP пока нет: корабль — это стопка блоков `VesselPartBlock`
  (двигатель, кресло, бак, обтекатель, силовая клетка...). Блоки Create
  Aeronautics в кучу AP не входят, поэтому удар по крылу CA = удар по силовой
  клетке. Отдельная клетка крыла появится, когда будет своя модель, а не чужая.
- Скорость берётся по смещению world-entity за тик (корабль двигается
  телепортом высоты, `getDeltaMovement()` у него нулевой). Телепорты clamp'ятся
  до 200 м/с, чтобы переход не считался ударом.
- Один контакт не чаще раза в 0.2 с; вложенная в породу клетка «грызётся» с
  минимальными 6 м/с, иначе застрявший корабль был бы бессмертным.

# Кто что собирает

ChemMod: материалы, полости, **свои баки** (адаптировать под космос).
AP: **двигатель**, **кресло управления** (этим помечают «это ракета»), крепление на поезд.

Без кресла куча — не ракета. Баки AP не ставит.

Солнечные панели — реалистичные свои в ChemMod, не склейка чужих модов.

Цех ступеней, если будет — AP. Литейка — ChemMod.

`docs/space/CHEMMOD_HANDOFF_RU.md` — текст для агента ChemMod.

# Кто что собирает

ChemMod: материалы, полости, **свои баки**, **всемирный газ** (среда мира: воздух,
давление, плотность — не газ из бака).
AP: **двигатель** (сила на аппарат), **кресло**, крепление на поезд, **стартовый стол**.

Без кресла куча — не ракета. Стол остаётся на земле.
Баки и атмосферу планеты AP не ставит.

Солнечные панели — реалистичные свои в ChemMod, не склейка чужих модов.

Цех ступеней, если будет — AP. Литейка — ChemMod.

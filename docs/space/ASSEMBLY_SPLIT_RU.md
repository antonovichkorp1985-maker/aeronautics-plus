# Кто что собирает

Ракета в Minecraft — не каталог готовых «деталей KSP» и не завод в AP.

Сейчас в AP стоят **заглушки** (баки трёх размеров, два двигателя, панели, кислород…).
Их **не удаляли**. Это не поэтапная сборка из ChemMod. Пока ChemMod не отдаёт
заготовки, игрок ставит эти блоки, компилятор считает физику.

## ChemMod (не этот репозиторий) — линия материалов

Литейка, сварка, сплавы, листы, сварной шов, топливо, кислород как вещество —
там. «Линия производства» живёт в ChemMod: из чего варить корпус и баки.

AP **не** строит свой сварочный цех и не копирует Create-завод «мельница → пресс → ракета».

## Aeronautics Plus — физика собранного и аппарат

Игрок ставит в мире то, что вышло из ChemMod (пока — заглушки). Компилятор уже
есть: сетка → порты → ступени → масса / тяга / тепло / питание.

AP не размножает SKU «ещё бак / ещё Merlin». AP добавляет то, что **не сваривается
из листа**:

- двигатель как цикл (жидкий / твёрдый / ядерный), когда ChemMod даст состав;
- «космитизация» панелей: вакуум, затмение, радиатор, шина, а не ещё одна земная панель;
- СЖО: кислород кабины ≠ LOX;
- вход в атмосферу: теплозащита и торможение;
- посадка: парашют, опоры, колёса под разный грунт.

Эти вещи тоже позже собирают из ChemMod, но **функция** живёт здесь.

```text
ChemMod: руда → сплав → лист / отливка / топливо
                ↓
         AP: поставить в мире → компилятор → ракета с физикой
```

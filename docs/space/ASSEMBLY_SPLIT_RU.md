# Кто что собирает

ChemMod: материалы, полости, **свои баки** (адаптировать под космос), **газы в баке** (что залито, T, P).
AP: **двигатель** (заявленные тяга/Isp, пока нет стыка), **кресло управления**,
крепление на поезд, **стартовый стол с зажимами**.

Без кресла куча — не ракета. Стол остаётся на земле, в массу ракеты не входит.
Баки AP не ставит.

Солнечные панели — реалистичные свои в ChemMod, не склейка чужих модов.

Цех ступеней, если будет — AP. Литейка — ChemMod.

`docs/space/CHEMMOD_HANDOFF_RU.md` — текст для агента ChemMod.

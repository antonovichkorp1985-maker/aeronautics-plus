# Следующий космический test-релиз

Текущая версия сборки — `0.2.2-test.11`. GUI и компилятор блоков Minecraft в ракету в неё не входят.

## Критерии `0.2.2-test.11`

- [x] GitHub Actions собирает мод без ошибок;
- [x] свободный `VesselBlueprint` компилируется в ступени;
- [x] валидируются баки, двигатели и топливные/окислительные связи;
- [x] `VesselState` хранит активную ступень и орбитальное состояние;
- [x] выполняются burn, расход топлива, изменение массы и delta-v;
- [x] вектор тяги и центр масс считаются в связанной системе ступени;
- [x] propagation и отделение ступени работают детерминированно;
- [x] ошибки сборки конструкции диагностируются текстом;
- [x] Ad Astra остаётся в сборке;
- [x] GUI и физическая модель ракеты ещё не считаются завершёнными.

Релиз публикуется после прохождения этих критериев, а не по календарной дате.

## Критерии `0.2.2-test.12`

- физические блоки Minecraft компилируются в `VesselBlueprint`;
- сохраняются порты, ступени и положения масс;
- Ad Astra не удаляется;
- GUI карты миссии ещё не требуется.

# Следующий космический test-релиз

Текущая версия сборки остаётся `0.2.2-test.10` до завершения следующего вертикального среза.

## Критерии `0.2.2-test.11`

- GitHub Actions собирает мод без ошибок;
- свободный `VesselBlueprint` компилируется в ступени;
- валидируются баки, двигатели и топливные/окислительные связи;
- `VesselState` хранит активную ступень и орбитальное состояние;
- выполняются burn, расход топлива, изменение массы и delta-v;
- propagation и отделение ступени работают детерминированно;
- ошибки сборки конструкции диагностируются текстом;
- Ad Astra остаётся в сборке;
- GUI и физическая модель ракеты ещё не считаются завершёнными.

Релиз публикуется после прохождения этих критериев, а не по календарной дате.

# Архив документации

Здесь хранятся исторические отчёты и superseded-спецификации. Они оставлены для
воспроизводимости решений и сравнения версий, но **не являются текущими требованиями**.
Если архивный документ противоречит активному, действует активный документ.

Актуальный индекс находится в [`../README.md`](../README.md).

## Правило архивирования

Документ переносится сюда только тогда, когда:

1. у него есть явно указанная актуальная замена либо он является датированным снимком;
2. полезные результаты и ограничения не потеряны;
3. входящие относительные ссылки обновлены;
4. в начале файла есть заметная архивная пометка.

Предметные научные справочники не являются устаревшими: единая программа задаёт их
порядок, но не заменяет подробную теорию, задачи и источники.

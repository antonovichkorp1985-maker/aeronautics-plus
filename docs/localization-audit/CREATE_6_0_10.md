# Create 6.0.10 — русский перевод Ponder и описаний

Проверка выполнена по точному исходному каталогу тега `mc1.21.1-6.0.10`, соответствующему установленному `create-1.21.1-6.0.10.jar`.

## До исправления

- английский каталог Create: **3 639** ключей;
- встроенный `ru_ru`: **3 621** записи, из которых текущему `en_us` соответствуют **3 619**;
- overlay RU-pack: 1 ключ формата времени;
- effective-покрытие: **3 619/3 639**;
- отсутствовало 20 ключей: 13 видимых строк и 7 намеренно пустых продолжений инструкций схематики.

Непереведённые видимые строки относились к синхронизации кладовщика с просмотрщиком рецептов, названиям клавиш-модификаторов и тегу пшеничного теста.

## Ponder — анимации-подсказки Create

В точной версии найдено **1 053** ключа Ponder. Они уже входят во встроенный русский каталог Create:

- effective-покрытие: **1 053/1 053**;
- отсутствующих ключей: **0**;
- совпадений с английским текстом: только допустимые `3:00`, `4:00` и название `Create`;
- английских предложений среди значений Ponder не осталось.

То есть эти надписи не были заново продублированы в RU-pack: игра получает их из штатного `ru_ru` самого Create. RU-pack дополняет только отсутствующие или исправляемые строки.

## После исправления

В overlay добавлены все 20 отсутствовавших ключей:

- интерфейс кладовщика и двусторонняя синхронизация с просмотрщиком рецептов;
- `Alt`, `Ctrl`, `Shift` как клавиши-модификаторы;
- название тега пшеничного теста;
- 7 пустых служебных продолжений с сохранением пустого значения оригинала.

Итог для Create 6.0.10:

- все ключи: **3 639/3 639**;
- Ponder: **1 053/1 053**;
- ключи описаний (`.description`/`.desc`): **168/168**;
- несовпадения форматных параметров: **0**.

Контроль закреплён скриптом `scripts/validate_create_localization.py`, который сравнивает exact JAR, встроенный русский каталог и RU-pack.

### Description (English, paste)

Aeronautics Plus is a NeoForge 1.21.1 addon for Create Aeronautics.

It adds large aircraft propellers and a Minecraft-free space core: freely built rockets compile into stages, tanks, engines, a payload under a jettisonable fairing, a crew habitat, RCS, control-moment gyros and solar panels. A Create train plus a rocket-mount block is the transporter. The stack is not launchable while still clamped.

This is a test build. There is no orientation GUI yet. Player launch uses Ad Astra until own physics can carry a player. Rotor blocks are not registered yet.

Code: MIT. Assets are original (no Create Aeronautics / Vanilla Walking meshes).

Requires: Minecraft 1.21.1, NeoForge 21.1.251+, Create Aeronautics 1.3.2+ (and therefore Create 6.0.10). Optional: TerraFirmaCraft.

Source: https://github.com/antonovichkorp1985-maker/aeronautics-plus

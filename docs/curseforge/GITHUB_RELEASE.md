## Title

Aeronautics Plus v0.2.2-test.27

## Body (English)

Aircraft and spacecraft parts for Create Aeronautics (NeoForge 1.21.1).

- Large 2/3/4-blade propellers and a shaft adapter
- Space core: stages, RP-1/LOX tank (O/F 2.3, common bulkhead), engine, fairing, payload, crew habitat, RCS, gyrodyne, solar panel
- Create train + rocket-mount is the transporter; no launch while clamped
- Fairing jettison drops shroud mass only; gyros despin without propellant if solar-powered

Alpha / test. No orientation GUI. Player launch still uses Ad Astra. Rotors are not registered.

JAR: `aeronauticsplus-0.2.2-test.27.jar`  
License: MIT. Original assets (no Create Aeronautics / Vanilla Walking meshes).

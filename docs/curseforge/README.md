# Карточка релиза (ещё не публиковать)

Сюда сложена вся информация для **будущего** выкладывания на GitHub Releases / CurseForge.
Сейчас это делать рано: сборки `-test.`, GUI нет, запуск игрока ещё Ad Astra.

Когда пользователь скажет публиковать:

1. Логотип: `logo.png`
2. Текст листинга (английский, CurseForge иначе отклонит): `DESCRIPTION.md`
3. Поля формы CurseForge: [`../CURSEFORGE_UPLOAD.md`](../CURSEFORGE_UPLOAD.md)
4. Черновик GitHub Release: `GITHUB_RELEASE.md`

Не загружать ChemMod из этого репозитория. Не ставить `-test.` JAR как CurseForge Release. Не брать `src/main/resources/icon.png` (это 32×32 внутриигровой значок).

## Name

Aeronautics Plus

## Summary (short blurb)

Aircraft and spacecraft parts for Create Aeronautics on NeoForge 1.21.1: large propellers, compiled rockets, and an orbital service bus.

## Description (paste)

Aeronautics Plus is a NeoForge 1.21.1 addon for Create Aeronautics. It adds the missing aircraft hardware and a separate space core so you can build real vehicles instead of decorative blocks.

**Aircraft.** Family of 2-, 3- and 4-blade propellers in wood, aluminum and steel, plus a shaft adapter that steps a Create shaft down to the propeller. These reuse Create Aeronautics’ MIT propeller pipeline, so they work with bearings, the wrench and Sable physics. Helicopter rotors are planned; they are not registered yet.

**Spacecraft.** Physical blocks compile into a vessel graph: structure, common-bulkhead RP-1/LOX tank (O/F 2.3), engine, stage separator, payload fairing, orbital payload, crew habitat, RCS, control-moment gyro and solar panel. A stack on a Create train rocket-mount is a transporter and cannot launch until it is unclamped. Fairing jettison drops only shroud mass. Gyros kill residual spin without propellant if they have solar power; RCS is a separate cluster, not the main engine.

This is an **alpha / test** build. There is no orientation GUI. Player launch still uses Ad Astra until own physics can carry a player.

**Requires:** Minecraft 1.21.1, NeoForge 21.1.251+, Create Aeronautics 1.3.2+ (and therefore Create 6.0.10). Optional: TerraFirmaCraft.

Code is MIT. Meshes and textures are original. Create Aeronautics and Vanilla Walking assets are not reused.

Source: https://github.com/antonovichkorp1985-maker/aeronautics-plus

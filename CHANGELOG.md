# Changelog

Все заметные изменения Aeronautics Plus документируются в этом файле.

## [Unreleased] — 0.2.1-dev

### Добавлено
- Survival-рецепты для прототипа и всех 9 серийных авиационных винтов.
- Таблицы добычи: каждый винт выпадает сам при разрушении и учитывает взрыв.
- Независимая проверка JSON, ресурсов, локализаций, рецептов, loot tables и размеров PNG (`scripts/validate_resources.py`).
- Runtime-диагностика регистрации: после common setup лог перечисляет все 10 item ID и творческую вкладку.

### Изменено
- README синхронизирован с уже выпущенной версией v0.2.0.
- Release workflow больше не содержит захардкоженные заметки v0.2.0 и сможет формировать заметки для следующих тегов.

## [0.2.0] — 2026-09-27

### Добавлено
- 9 авиационных винтов: дерево, алюминий и сталь × 2, 3 и 4 лопасти.
- Общая spec-driven реализация тяги, airflow и радиуса на базе Create Aeronautics.
- Блокстейты, модели, собственные текстуры 16×16 и локализации en/ru.
- Автоматическая сборка GitHub Release при публикации тега `v*`.

# Aeronautics Plus

Авиа-комплектующие для **Create Aeronautics** (MC 1.21.1, NeoForge, Java 21): авиационные пропеллеры (2/3/4 лопасти, крупные диаметры), несущие и рулевые винты, крылья, элероны/рули направления, рули высоты/закрылки и интеграционные крепления под сторонние силовые установки.

## Почему аддон, а не «своё»
Части Create Aeronautics строятся на публичных (MIT) классах: `BasePropellerBlock` / `BasePropellerBlockEntity` (Sable-API `BlockEntityPropeller`) + `PropellerActorBehaviour` (тяга на корабле) + гиро-подшипник с наклоном вектора тяги (`setTilt/setStrictTilt` — основа вертолётного управления). Мы наследуем их же базовые классы — наши части автоматически дружат с подшипниками, гаечным ключом, пондерами и физикой Sable.

## Дорожная карта (приёмка на каждом этапе)
| Этап | Что | Приёмка |
|---|---|---|
| Э1 | Каркас + CI (этот коммит) | CI зелёный, jar собирается |
| Э2 | v0.1: прототипный авиационный винт | вращается + тянет корабль CA |
| Э3 | v0.2.0: семейство винтов (2/3/4 лопасти, дерево/алюминий/сталь, большие диаметры) | 9 новых блоков зарегистрированы через CA BasePropellerBlock; тяга/airflow/radius задаются per-spec и дальше балансируются в тест-мире |
| Э4 | v0.3: несущий/рулевой винты (циклический/общий шаг через tilt гиро-подшипника) | висение + управление |
| Э5 | v0.4: крылья, элероны, рули, закрылки (зависит от lift-модели Sable) | стабильный горизонтальный полёт |
| Э6 | v0.5: реактивная интеграция без дубляжа More Propulsion / Create Propulsion: Simulated (мотогондолы, пилоны, KubeJS/TFMG fuel shim, совместимость с Aeronautics) | сторонние реактивные двигатели корректно ставятся на конструкции CA и используют согласованное топливо |

## Реактивная тяга и дубли

Create Propulsion: Simulated и More Propulsion уже закрывают полноценные реактивные двигатели/сопла. Поэтому Aeronautics Plus **не должен заново добавлять те же сопла как отдельную параллельную ветку**. Наша зона, если она понадобится: крепления, мотогондолы, управляющие поверхности, KubeJS/TFMG fuel shim и совместимость этих двигателей с конструкциями Create Aeronautics.

## Текущее состояние

- Стабильный релиз: **v0.2.0**.
- В разработке: **v0.2.1-dev** — рецепты и таблицы добычи для всех 10 винтов, проверки целостности ресурсов, переработанные модели и текстуры винтов.
- Новые модели используют отдельные вал, ступицу, обтекатель и сужающиеся лопасти; трёхлопастной вариант имеет однозначный Y-образный силуэт.
- У всех винтов отключено отсечение как у полного куба, чтобы их геометрия не скрывала грани соседних блоков.
- Числа тяги/airflow/radius пока стартовые и требуют балансировки в тестовом мире.

Все винты доступны в творческой вкладке Aeronautics Plus. В v0.2.1 добавлены survival-рецепты: материал лопастей (`minecraft:planks`, `c:ingots/aluminum`, `c:ingots/steel` или `c:ingots/iron` для прототипа) вокруг `create:shaft`.

## Проверка установки

1. В списке модов должна быть строка `Aeronautics Plus <версия> (aeronauticsplus)`; в `latest.log` — сообщение `Aeronautics Plus registry ready: 10 propeller items` (начиная с v0.2.1).
2. В мире с командами проверить реестр напрямую:
   - `/give @s aeronauticsplus:prototype_propeller`
   - `/give @s aeronauticsplus:aluminum_three_blade_propeller`
3. В творческом поиске искать `авиационный` или `винт`; отдельная вкладка называется **Aeronautics Plus** и имеет иконку алюминиевого трёхлопастного винта. Моды-организаторы вкладок могут перенести её на другую страницу.
4. В EMI выбрать боковую страницу **Index**, а не **Craftables**, и искать `@aeronauticsplus`. Обычный поиск `Aeronautics Plus` не работает, если в EMI отключён поиск по имени мода.

Важно: стабильный v0.2.0 не содержит survival-рецептов и loot tables, поэтому его предметы отсутствуют на странице EMI **Craftables**. Это исправлено в v0.2.1-dev.

## Сборка
GitHub Actions собирает jar автоматически на каждый push (вкладка **Actions** → артефакт `aeronauticsplus-jars`).
Локально: `gradle build` (JDK 21, Gradle 8.9).
Проверка ресурсов без запуска Minecraft: `python3 scripts/validate_resources.py`.
Исходные ванильные cuboid-модели и 16×16-текстуры винтов воспроизводимо генерируются командой `python3 scripts/generate_propeller_models.py`; сторонние ассеты не используются.

# Текущий метр
! [Что-то пахнет тостом]block:powergrid:current_gauge

Протокол взаимодействия с счетчиком тока поддерживает как операции чтения, так и записи.
Любое использование этого протокола для насилия не дает гарантии.

При записи в последовательный интерфейс счетчика тока допускаются как отрицательные, так и положительные значения, эти значения перемещают запятую от чтения.
Когда`0`возвращается в единицу Ампера, когда`-3`возвращается в мА.
Используйте любые экстремальные значения на свой страх и риск, любые значения ниже -3 не поддерживаются и *WILL* аннулируют вашу гарантию.

При чтении из последовательного интерфейса счетчика тока значение масштабируется до нужного блока на основе конфигурации.

Мы не несем ответственности за любые травмы, вызванные неправильными прочтениями. Этот протокол предназначен только для использования. Используйте на свой страх и риск. *

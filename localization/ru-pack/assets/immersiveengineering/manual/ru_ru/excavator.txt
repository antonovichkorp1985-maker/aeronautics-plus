Экскаватор
Лучше, чем гномы
<&full>Экскаватор является одной из вершин современной промышленности, способной копать.<link;mineral_deposits;minerals>Вены обычно недоступны.<np>
Из-за интенсивных требований извлечения разреженных вен из породы, экскаватор представляет собой сложную машину, которая требует:<config;i;machines.excavator.consumption>Flux/t для работы.<br>
Добыча начинается с нижней оконечности колеса ковша, а материалы выводятся из задней части кронштейна двигателя.<br>
Три вилки для двигателя берут мощность сбоку, а сзади есть панель управления из красного камня.<br>
По мере того, как экскаватор выкапывает руды, выход вены медленно уменьшается, но минеральное месторождение может обеспечить максимум.<config;i;machines.excavator.yield>Блоки руды.<br>
Структура состоит из двух частей: Двигатель, показанный на следующей странице, и колесо ковша, отображаемое на следующей, которое вписывается в «брекеты» двигателя. Полную конструкцию можно собрать с помощью Инженерного молота на заднем центральном блоке тяжелой техники.<br>
<&wheel>Колесо может быть сформировано самостоятельно с помощью Инженерного молота на центральном стальном блоке.
<&engine>Двигатель может быть сформирован сам по себе через тяжелый инженерный блок порта заднего центра и сформирует колесо ковша с ним при условии, что он правильно расположен.

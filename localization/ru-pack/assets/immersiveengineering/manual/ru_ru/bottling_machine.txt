Машина для розлива
Заполните ее!
<&multiblock>Машина для розлива заполняет жидкости в контейнеры или формы.<br>
Структура создается, как показано выше, но может быть зеркальной. Чтобы сформировать его, щелкните правой кнопкой мыши центральный конвейер с молотком инженера. Направление конвейеров важно.<np>
Машина может хранить 8 ведер жидкости, которая поступает через порты на металлическом баке. Энергия поступает через соединение в верхней части противоположной стороны.<br>
Как правило, машина для розлива сможет заполнить любой контейнер, который имеет заполненную версию (ведро, стеклянная бутылка). Он также будет принимать другие предметы, которые могут хранить жидкости, такие как<link;mining_drill;Mining Drill;start>или<link;jerrycan;Jerrycan;start>.<br>
Машина будет удерживать контейнер до тех пор, пока он не будет полностью заполнен, или машина не будет снабжаться дополнительной жидкостью.<br>
Это позволяет ему заполнять еще большие контейнеры при условии, что он получает постоянный вход жидкости.<br>
Это поведение может быть отключено путем подкрадывания и щелчка правой кнопкой мыши с помощью Инженерного молота.<np>
<&potions>Машину можно использовать для бутылочки любых зелий, которые были заварены в<link;mixer;Mixer>.<br>
Кроме того, он служит для создания<link;resin_and_duroplast;duroplast items;duroplast_sheet>из смолы и<link;industrial_fluids;oxidize copper blocks;redstone_acid>с красной кислотой.

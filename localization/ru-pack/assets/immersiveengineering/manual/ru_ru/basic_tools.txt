<&engineers_hammer>Инженерные молотки являются одним из самых важных инструментов в наборе инструментов инженера.<br>
Его можно использовать для настройки и формирования машин, а также дробить руды.<np>
<&wirecutters>§lПроводные катера инженера§rОни используются для удаления всех проводов, подключенных к блоку, просто щелкнув по нему правой кнопкой мыши.<br>
Проводники также могут удалять провода, натянутые между полюсами при работе с ними.<np>
<&screwdriver>Отвертки инженера - еще один распространенный элемент в наборах инструментов.<br>
Они используются для точной конфигурации на определенных частях оборудования.<np>
<&multimeter>§lмультиметры§rОни используются для измерения связей.<br>
Нацелив его на любое хранилище энергии или щелкнув правой кнопкой мыши, он прочитает его текущее хранилище.<br>
Sneak+rightclick два разъема для расчета средней потери между ними.<br>
Мультиметры также могут использоваться для считывания уровней красного камня блоков, таких как соединители красного камня и пыль красного камня.

Внешний обогреватель
Теперь ты готовишь с флюсом!
<&recipe>Внешний нагреватель генерирует тепло от Flux, которое он выдает в тепловые отверстия по бокам.<br>
Он не может производить восстановительные атмосферы, используемые в взрывных печах, древесном дыме для сохранения пищи или температурах, необходимых для печи.<br>
При размещении рядом с обычной печью эта тепловая энергия обеспечит печь теплом без потребления топлива.<br>
Боковые стороны нагревателя могут быть настроены с помощью Инженерного молота, прокрадывающегося на противоположную сторону.<br>
Нагреватель будет потреблять 8 Flux/t для каждой печи, которую он должен нагревать. Чтобы предварительно разогреть печь, потребуется в четыре раза больше, пока печь не будет находиться при температуре.<br>
Когда печь находится при максимальной температуре, внешний обогреватель будет потреблять в общей сложности.§o32 флюс/т§rна печь для увеличения скорости плавки, если сигнал красного камня не отключает ускорение скорости.<br>
Только печи, в которых есть предметы для плавки и пространство для плавки, будут нагреваться.

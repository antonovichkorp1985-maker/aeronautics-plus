Машинный интерфейс
Поиск сложных условий быстро
<&recipe>С усложнением многоблоковых машин отслеживание их потребностей становится довольно сложным.<br>
Хотя<link;redstone_probe;comparator signals>Может дать некоторое представление о количестве предметов внутри, только машинный интерфейс может обеспечить более подробную оценку и отправить сигналы.<np>
При размещении на поверхности управления красным камнем мультиблока открытие GUI позволит создать множество условий, с помощью которых можно будет выводить сигнал.<br>
Нажмите кнопку «Добавить условие», чтобы добавить новую строку. В пределах этой строки первая кнопка служит для ее повторного удаления, вторая - для настройки цвета сигнала для вывода.<np>
Далее следуют два выпадающих меню, одно для выбора типа проверки (например, «Машина активная», «Ввод продукта», «Вывод жидкости») и одно для выбора условия.<br>
Большинство проверок поддерживают «Вывод сравнителя» для силы сигнала, которая масштабируется до хранимых элементов / жидкости / энергии. Существуют также различные варианты, такие как «75% заполненных» или «пустых».<np>
Как только условие будет согласовано, машинный интерфейс выдаст соответствующий сигнал на сконфигурированном цветном канале любому прикрепленному<link;redstone_wiring;Redstone Interface Connector;bundled>.<br>
В дополнение к отправке, машинный интерфейс также может принимать сигнал красного камня и выводить его на подключенную машину. Цвет сигнала для этого настроен в правом нижнем углу GUI.<np>
Это позволяет использовать<link;logic_unit;Logic Unit>Чтобы оценить сигналы, поступающие от машины, а затем отправить один назад, чтобы включить или отключить его!

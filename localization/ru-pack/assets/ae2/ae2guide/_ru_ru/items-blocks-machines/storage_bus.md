Вы когда-нибудь хотели сохранить своего монстра вместо того, чтобы заменить его чем-то разумным? Представляем складской автобус!

Шина хранения превращает инвентарь, к которому она прикасается, в [сетевое хранилище]../ae2-mechanics/import-export-storage.md).
Он делает это, позволяя сети видеть содержимое этого инвентаря, а также нажимая и вытягивая из него.
Для того, чтобы выполнить [устройства]../ae2-mechanics/devices.md) толкать и вытягивать из сетевого хранилища.

## Фильтрация

По умолчанию автобус будет хранить все. Элементы, вставленные в слоты фильтра, будут действовать как белый список.
Это позволяет хранить эти конкретные предметы.

Элементы и жидкости могут быть втянуты в слоты от JEI / REI, даже если у вас нет этого элемента.

Нажмите правой кнопкой мыши на контейнер с жидкостью (например, ведро или резервуар с жидкостью), чтобы установить эту жидкость в качестве фильтра вместо элемента ведра или резервуара.

##Настройки

* Автобус может быть разделен (фильтрован) на то, что в настоящее время находится в соседнем инвентаре.
* Сеть может быть запрещена или разрешена для просмотра предметов в соседнем инвентаре, которые шина не может извлечь.
(например, шина для хранения не может извлекать элементы из среднего входного слота устройства).<ItemLink id="inscriber" />)
* Шина может фильтровать как вставку, так и извлечение или просто вставку.
* Автобус может быть двунаправленным, только для вставки или только для извлечения

## Обновления

Автобус хранения поддерживает следующие [обновления]upgrade_cards.md):

*   <ItemLink id="capacity_card" />Увеличивает количество фильтрующих слотов
*   <ItemLink id="fuzzy_card" />позволяет фильтровать шину по уровню повреждений и/или игнорировать элемент NBT
*   <ItemLink id="inverter_card" />Переключает фильтр из белого списка в черный.
*   <ItemLink id="void_card" />пустоты предметов, вставленных, если прилагаемый инвентарь полон, полезный для остановки ферм от резервного копирования. Будьте осторожны, чтобы разделить это!

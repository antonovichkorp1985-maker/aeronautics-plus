# View Cell #

<ItemImage id="view_cell" scale="2" />

View Cells используются для фильтрации отображения [терминалов]terminals.md). Вы разделяете их в<ItemLink id="cell_workbench" />.

Например, скажем, вы хотите, чтобы терминал отображал только выбор каменных строительных материалов. Разделить ячейку зрения на те
Поместите его в терминал, и только эти предметы будут показаны.

Просмотровые ячейки являются аддитивными, если у вас есть ячейка для просмотра дубовых досок и ячейка для просмотра булыжника, помещение обоих в покажет
как доски, так и булыжник.

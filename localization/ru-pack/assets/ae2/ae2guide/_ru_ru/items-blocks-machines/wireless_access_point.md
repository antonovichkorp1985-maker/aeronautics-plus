#Точка беспроводного доступа

<BlockImage id="wireless_access_point" p:state="has_channel" scale="8" />

Позволяет беспроводной доступ через<ItemLink id="wireless_terminal" />.
Диапазон и энергопотребление определяются исходя из количества<ItemLink id="wireless_booster" />установлен.

Сеть может иметь любое количество точек беспроводного доступа с любым количеством
из<ItemLink id="wireless_booster" />в каждом из них, что позволяет оптимизировать энергопотребление
Измените свой ассортимент, изменив его.

Требуется [канал]../ae2-mechanics/channels.md).

Также используется для связывания [беспроводных терминалов]wireless_terminals.md)

Беспроводной бустер

<ItemImage id="wireless_booster" scale="2" />

Используется для увеличения диапазона беспроводной точки доступа.

# Волокно кварца

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/assemblies/quartz_fiber.snbt" />
<IsometricCamera yaw="195" pitch="30" />
</GameScene>

Кварцевое волокно используется для разделения мощности между [сетями]../ae2-mechanics/me-network-connections.md), сохраняя их отдельно. Это позволяет вам управлять
[подсети]../ae2-mechanics/subnetworks.md)
без необходимости устанавливать акцепторы энергии и силовые кабели повсюду. Он также может использоваться для предотвращения подключения кабелей.
при использовании кабелей различного цвета или при использовании<ItemLink id="cable_anchor" />Это дешевле и эффективнее.

Они [кабельные части]../ae2-mechanics/cable-subparts.md).

# Зарядное устройство

<BlockImage id="charger" scale="8" />

Зарядное устройство предоставляет способ зарядки
Поддерживаемые инструменты и<ItemLink id="certus_quartz_crystal" />.

Мощность может быть обеспечена через верхнюю или нижнюю часть, через кабели AE2.cables.md), или другие силовые кабели мода. Он может
Принять энергию AE2 (AE) или Forge Energy (FE). Предметы могут быть вставлены или удалены с любой стороны. Только результаты могут
удаляется, поэтому нет необходимости в фильтрах для предотвращения удаления кристаллов кертуса вместо заряженного кертуса. Можно вращать с помощью a
<ItemLink id="certus_quartz_wrench" />Для облегчения автоматизации.

Можно использовать для создания<ItemLink id="charged_certus_quartz_crystal" />
из<ItemLink id="certus_quartz_crystal" />и<ItemLink id="meteorite_compass" />из<ItemLink id="minecraft:compass" />.

Чтобы питать его вручную, поместите<ItemLink id="crank" />сверху или снизу и щелкните правой кнопкой мыши, пока товар не заряжен.

Он также выступает в качестве рабочей станции для [исследователя Fluix].fluix_researcher.md).

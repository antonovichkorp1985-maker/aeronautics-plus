# Моя грудь

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/chest.snbt" />
</GameScene>

ME Chest действует как миниатюрная сеть.<ItemLink id="terminal" />, <ItemLink id="drive" />и<ItemLink id="energy_acceptor" />.
Хотя его можно использовать в качестве крошечной сети хранения, его емкость составляет всего одну ячейку хранения.../items-blocks-machines/storage_cells.md)
Он имеет ограниченную полезность как таковую.

Вместо этого он полезен для взаимодействия с ячейкой хранения, установленной внутри нее. Интегрированный терминал может видеть только
Вещи, находящиеся в движке, в то время как [устройства]../ae2-mechanics/devices.md) в общей сети может осуществлять доступ к элементам в любом [сетевом хранилище](../ae2-mechanics/import-export-storage.md),
В том числе сундуки.

Он имеет 2 различных графических интерфейса и предназначен для транспортировки предметов. Взаимодействие с верхним терминалом открывает интегрированный терминал. Предметы могут быть вставлены в
установленная ячейка хранения через это лицо, но не извлеченная. Взаимодействие с любым другим лицом открывает GUI слотом для ячейки хранения
и приоритетных параметров. Ячейка может быть вставлена и удалена по элементу логистики только через лицо с ячейкой.

Его можно вращать с помощью<ItemLink id="certus_quartz_wrench" />.

Он имеет небольшой буфер хранения энергии AE, если не в сети с ячейкой энергии.../items-blocks-machines/energy_cells.md),
Вставка или извлечение слишком большого количества предметов сразу может привести к его потемнению.

Терминал может быть окрашен в<ItemLink id="color_applicator" />.

## Приоритет

Приоритеты можно установить, щелкнув гаечный ключ в правом верхнем углу GUI слота ячейки.
Предметы, входящие в сеть, начинаются с наиболее приоритетного хранилища.

Удалить из хранилища с наименьшим приоритетом. Эта система приоритета означает, что элементы вставляются и удаляются.
Из сетевого хранилища будут заполнены хранилища с более высоким приоритетом, а хранилища с более низким приоритетом будут опустошены.

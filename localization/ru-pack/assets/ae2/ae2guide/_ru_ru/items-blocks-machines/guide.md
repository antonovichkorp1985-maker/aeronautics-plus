# Руководство

<ItemImage id="guide" scale="8" />

#### Это руководство, которое вы сейчас читаете, для всех ваших потребностей в руководстве AE2.

* Доступ к боковой панели слева, чтобы найти таблицу содержимого
* Многие страницы имеют интерактивные сцены. Если сцена имеет ![Plus](../активы/диаграммы/plus.png)
[Minus] (../активы/диаграммы/minus.png) (zoom) кнопки рядом с ним, вы можете повернуть и переместить камеру.
Левый клик и перетащите для вращения, правый клик и перетащите для перевода.

# Пространственный пилон

<BlockImage id="spatial_pylon" p:powered_on="true" scale="8" />

Пространственный пилон используется в [пространственном IO]../ae2-mechanics/spatial-io.md) для формирования пространственного поля и определения объема
быть затронутым.

Каждая непрерывная линия пилонов использует 1 [канал]../ae2-mechanics/channels.md)

Линии пилонов должны иметь длину не менее 2 блоков.
